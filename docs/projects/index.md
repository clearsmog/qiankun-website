    <span class="project-title">Cisco Systems Equity Valuation (CSCO)</span>
    <span class="project-desc">

Built from a bottom-up free-cash-flow-to-firm (FCFF) discounted cash flow model, peer multiples, a reverse DCF, and a 50,000-trial Monte Carlo simulation, with a formula-driven Excel audit workbook.

    <span class="project-title">Board Gender Diversity and Corporate ESG</span>
    <span class="project-desc">

A California-law quasi-experiment then tests, and does not find, a causal link.
