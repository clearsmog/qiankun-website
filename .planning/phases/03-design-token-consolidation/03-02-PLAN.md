<objective>
Apply the recipe plan 03-01 proved in a browser to the remaining eleven chart components, and finish
the brand-colour deduplication across the five `.vitepress` JavaScript and Vue occurrences that
remain.

Purpose: eleven near-identical edits invite copy-paste drift, and the one option that matters —
`{ flush: 'post' }` — is invisible to every check except a human watching a chart during a toggle.
The defence is not per-file prose but count-based gates: observers must go to zero and post-flush
watchers must land on exactly twelve. A missed file shows up as an arithmetic mismatch, not as a
subtle rendering bug found three phases later.

On deduplication, note a scope correction. CONTEXT.md records the brand hex appearing in four places
and grants discretion over two of them. A fresh scan finds **seven** in `docs/.vitepress`, not four —
CONTEXT.md's list omits `ProjectChart.vue`'s brand fallback, `ProjectChart.vue`'s own palette head,
and `EHistogram.vue`'s `color` prop default. That is the same class of undercount as DES-08's stale
"both observers" wording. All five non-canonical occurrences are wired to the token here, because
CONTEXT.md's discretion clause sets the bar explicitly: one canonical definition plus
*explicitly-justified* fallbacks, never a silent duplicate. A palette head and a prop default that
markdown never overrides are operative values, not fallbacks, so justifying them as such would be
false.

Substituting the imported token for a literal of identical value is a spelling change, not a palette
change — the rendered colour sequence is unchanged, which keeps this inside the UI-SPEC's
visual-neutrality contract and out of Phase 4's palette work.

Two behaviours are deliberately preserved rather than improved. `VizEChart.vue`'s reaction is
`chartRef.value?.resize?.()`, which does not itself re-read colours; RESEARCH.md establishes it is
vestigial but harmless, because the ten wrapper components recompute their own `option` and
`vue-echarts` reacts to that prop. Convert its trigger; do not redesign it. And `ProjectChart.vue` is
registered globally but referenced by zero markdown files — dead code, but deleting it belongs to a
later audit, not to a token-consolidation phase.

Output: twelve components on `useData().isDark`, zero DOM class observers, and the brand hex reduced
to two cross-referenced literals across all of `docs/.vitepress`.
</objective>
