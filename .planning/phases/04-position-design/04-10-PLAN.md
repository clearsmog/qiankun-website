<objective>
Run the cross-cutting checks that cannot honestly be performed one file at a time, and finish the
Writing index.

Purpose: four of Phase 4's requirements are defined comparatively. DES-06 asks for consistency
"checked side-by-side across every remaining page", DES-10 names a specific viewport, DES-11 asks for
dark-mode correctness "including all chart exhibits", and EXH-03 asks for formatting consistency
"within and across all five case studies". A per-file acceptance criterion in plans 04-07 through
04-09 proves each page is internally consistent; it cannot prove the five agree with each other or
with the rest of the site. POS-02's acceptance test is comprehension by a reader who has not seen the
project, which by construction cannot be self-assessed by the context that wrote the copy.

Fix-forward policy: where this sweep finds a defect, fix it in whichever file carries it and record
the fix in the SUMMARY. Nothing else runs in this wave, so there is no file-ownership conflict.

Output: a finished Writing index, a recorded cross-page audit, and either a clean bill or a list of
fixes applied.
</objective>
