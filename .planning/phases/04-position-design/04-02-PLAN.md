<objective>
Build the token layer this whole phase consumes: an eight-step spacing scale, an eight-step type
scale on the 1.200 minor-third ratio, two weight steps, two line-heights, a single card radius, two
semantic colour tokens, and a real `prefers-reduced-motion: reduce` block — then migrate every
literal already inside `custom.css` onto them.

Purpose: DES-03 requires the type scale, weights, and line-measure to be defined once and consumed
everywhere. Six of the nine other plans in this phase reference tokens that do not exist until this
plan lands. This is also where the four raw brand RGB literals carried forward from Phase 3
verification finally fold into `--vp-c-brand-1`.

Output: one file, `custom.css`, carrying the complete design-token vocabulary for the site.
</objective>
