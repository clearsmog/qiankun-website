Remove every colour literal from the script block. For anything sequential or categorical — the
factor weights, the sector mix, the tracking-error components, and any metric tile whose colour means
only brand emphasis — delete the colour or accent key entirely and let the component's theme-reactive
palette fallback take over. This page's own metrics array already omits the accent key on some
entries and is the shape to match. For any element signalling an unfavourable finding, such as a loss
figure in the risk exhibit, keep the key and set it to the negative semantic name that plan 04-06
taught the components to resolve; a favourable finding takes the positive name.

**Neutral greys are an exception — keep their key.** On these two pages that is the `'Market'`
benchmark series in the global-equity risk exhibit (`color: '#86868b'`) and any comparable baseline.
A grey marks a series as recessive — a benchmark or reference the plotted data is measured against —
and deleting the key would give it a saturated palette hue, making the benchmark read as a competing
data series. That is a readability regression against DES-12 and EXH-05. No new token is required:
`#86868b` is exactly `--vp-c-text-3`, already exposed by `themeTokens()` as `text3`
(`echarts-setup.js:72`), and `#6e6e73` is `--vp-c-text-2`, exposed as `text2`. Pass the semantic name
so the component resolves it through `themeTokens()` — never a `var()` string. This removes the
literal (DES-07) and re-themes in dark mode (DES-11) while preserving the recessive reading. Record
in the SUMMARY which series took `text3` versus `text2`.

Do not write a `var()` reference into any chart data array; canvas rendering cannot resolve it. The
only place a `var()` reference is valid is a `HeroMetrics` accent, which is applied as a CSS custom
property.

Finally, enumerate every numeric value the page renders — Snapshot tile values, chart data labels,
axis ticks, and figures in prose — and confirm each against its type's rule in UI-SPEC's formatting
table: percentages to one decimal, per-share currency to two, aggregate currency to one with its unit
suffix, counts and ratio-style metrics unpadded, thousands separators on every integer of four digits
or more. Produce the enumeration in the SUMMARY; the audit is the deliverable, not the diff. Then
confirm all four exhibit subtitles state a takeaway rather than only describing what is shown.
