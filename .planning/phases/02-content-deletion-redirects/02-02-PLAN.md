## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository → client JS bundle | Component code registered in `enhanceApp` ships to every visitor's browser; unused registrations enlarge the bundle and widen the client-side surface. |
| build-time data loader → rendered HTML | `blog-posts.data.js` ran at build time and inlined its output into the homepage; removing it removes the homepage's only data dependency. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-05 | Denial of Service | `docs/.vitepress/theme/index.js` | low | mitigate | A dangling import of a deleted component breaks the bundle and takes the whole site down on the next deploy, not just one page. Mitigated by making file deletion and registration removal a single atomic task, and by gating on a green `npm run docs:build` plus exact registration and import counts. |
| T-02-06 | Tampering | `docs/index.md` feature card SVG gradient ids | low | mitigate | Duplicate `<defs>` ids across simultaneously rendered cards cause one icon to silently adopt another's gradient — a rendering defect on the first screen a recruiter sees. Gated by asserting the count of gradient id matches equals the count of unique matches. |
| T-02-07 | Information Disclosure | deleted component source | low | accept | The six components remain in git history. They contain no secrets — they are presentational SVG chart renderers — so history retention discloses nothing. |
| T-02-08 | Tampering | npm/pip/cargo installs | n/a | accept | This phase installs no packages; RESEARCH.md records the Package Legitimacy Audit as not applicable. No install task exists in this plan. |
