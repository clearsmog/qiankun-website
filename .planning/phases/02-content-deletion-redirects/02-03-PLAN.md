    this audit mirror CI, which builds from a fresh checkout with no cache at all. This matters

    Run the production build. Because `ignoreDeadLinks` is unset in this project's config and its
    compiled default is false, the build hard-fails on any dead relative markdown link rather than
    warning. A clean exit is therefore real evidence for PRUNE-07 across all markdown content, not
    a formality — this is the gate, not a smoke test.

    Audit `docs/public/_redirects` against the locked mapping. It must hold exactly six rule lines
    once comment and blank lines are filtered out. Every rule is three whitespace-separated fields
    and ends in the status code 301, since the locked decision is that every deleted URL redirects
    rather than returning a gone status — a dead end is worse than a slightly-off destination on a
    URL printed on a CV. Confirm the four retired section and post routes are each covered, that
    the two section routes target the site root and the two post routes target the writing index,
    and that no destination field contains a splat or placeholder token. A templated destination
    would be an open-redirect surface; all six destinations must be fixed internal paths.

    Confirm the redirect file reached the deploy artifact. `docs/public/` is VitePress's default
    static passthrough and the GitHub Actions workflow deploys the built output directory
    verbatim, so the file must appear at the output root and be byte-identical to its source. This
    was proven for the first rule pair by plan 02-01's tracer; re-confirm it for the finished
