## CI/CD & Deployment

**Hosting Platforms:**
1. **Cloudflare Pages (Primary)**
   - Deployment method: `npx wrangler pages deploy`
   - Triggered by: GitHub Actions on push to `main` branch
   - Workflow: `.github/workflows/deploy.yml`
   - Project name: `qiankun-website`
   - Requires: `CLOUDFLARE_API_TOKEN` environment variable

2. **AWS Amplify (Secondary/Backup)**
   - Deployment method: Auto-deploy on Git push to `main`
   - Build configuration: `amplify.yml`
   - Build command: `npm run docs:build`
   - Output directory: `docs/.vitepress/dist`
   - Node caching: Enabled for faster builds
   - Requires: AWS credentials (AWS CLI optional for deployment.sh status checks)

**CI Pipeline:**
- GitHub Actions (`.github/workflows/deploy.yml`)
- Runs on: Ubuntu latest
- Steps:
  1. Checkout code (`actions/checkout@v4`)
  2. Setup Node.js v22 with npm cache (`actions/setup-node@v4`)
  3. Install dependencies: `npm ci --legacy-peer-deps`
  4. Build site: `npm run docs:build`
  5. Deploy to Cloudflare Pages: `npx wrangler pages deploy`

**Manual Deployment:**
- Script: `deploy.sh` - Orchestrates build, commit, push, and Amplify status checks
- Commands:
  - `./deploy.sh` - Full deployment with prompts
  - `./deploy.sh --skip-build` - Skip local verification, just push
  - `./deploy.sh -m "message"` - Custom commit message
  - Checks AWS Amplify status if AWS CLI is installed
